## How to install

1. Open **Settings**
2. Go to **Time & Language** → **Language & region**
3. Click **Add a language**
4. Search for **日本語 (Japanese)** and select it
5. Click **Next** → **Install**
6. The **Microsoft IME** is added automatically

## How to use

Switch keyboards with **Alt + Shift** or press **Win + Space**.

Romaji is the way to write Japanese sounds using latin letters. Type in romaji and the IME (Input Method Editor) converts it to Japanese:

1. Type `neko` → ねこ appears
2. Press **Space** to convert → 猫
3. Press **Enter** to confirm

Tip: press **Space** multiple times to cycle through kanji candidates.

### Tips

- **Double consonant** → type the consonant twice: `kk`, `ss`, `tt`, `pp` → っ (e.g. `kitte` → きって)
- **Long vowel in katakana** → type `-` for ー (e.g. `ke-ki` → ケーキ)
- **n before a vowel** → type `nn` to get ん (e.g. `konnichi` → こんにち)
