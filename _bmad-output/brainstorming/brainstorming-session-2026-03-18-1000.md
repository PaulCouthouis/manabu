### Morphological Analysis (2nd pass) — Décomposition en skills atomiques

**Focus :** Décomposer systématiquement les canaux d'interaction en skill types et instances

#### Décisions architecturales fondatrices

**Modèle type/instance :**
- **Skill type** (abstrait) = ce qui figure dans l'arbre (ex: "Reconnaître un hiragana")
- **Skill instance** (concret) = ce que le SRS track (ex: "Reconnaître あ")
- L'arbre contient les types. Le système de progression track les instances.

**Modèle en couches (insight clé) :**
- **Couche perception/décodage** = spécifique au canal (audio ou visuel)
- **Couche sémantique** = partagée quel que soit le canal d'entrée
- La compréhension est la même que le mot soit lu ou entendu — seul le chemin d'accès diffère

**Unification vocabulaire/grammaire (insight majeur) :**
- Les skills core (réceptifs/productifs) sont universels — ils s'appliquent du mot isolé à la phrase complexe
- La grammaire ne crée PAS de nouveaux skill types — elle crée des **instances plus difficiles** des mêmes skills
- Les connaissances grammaticales sont des **prérequis** qui déverrouillent les instances complexes

#### Recherche académique intégrée

**Nation (2001) — 9 aspects de connaissance d'un mot :**
Framework de décomposition à 3 macro-catégories (Forme, Sens, Usage) × 3 aspects × réceptif/productif = 18 micro-skills théoriques. Adapté pour le japonais :
- Aspects 1-4 (forme + lien forme↔sens) → nos skills atomiques core
- Aspects 5-6 (concept, associations) → émergent avec l'exposition, pas des skills isolés
- Aspects 7-9 (grammaire, collocations, contraintes) → dimensions de progression, pas skills séparés
- Extension japonaise : "forme écrite" se split en kanji→sens et lecture→prononciation (Hatta et al. 2020)

**15 dimensions identifiées dans la littérature (CEFR, JF Standard, Bachman, DeKeyser, Nation, Levelt, Skehan, Hatta) :**
- 7 structurantes pour l'arbre (modalité, directionalité, unité linguistique, type de compétence, aspects du mot, route kanji, registre)
- 4 caractérisant la progression (automaticité, CAF, implicite/explicite, profondeur vocab)
- 4 contextuelles/filtres (domaine d'usage, fonction communicative, condition d'apprentissage, compétence interculturelle)

**Compétence pragmatique :** intégrée comme dimension de progression dans les skills de production, pas comme canal séparé. Exemples : すみません (3 sens), ちょっと... (refus implicite), choix de registre.

#### Taxonomie complète : 17 skill types

**FONDATION — 3 skill types (points d'entrée, aucun prérequis)**

| ID | Skill type | Direction | Instances |
|---|---|---|---|
| F1 | Reconnaître un hiragana | voir → son | ~80 (base + yōon + gemination) |
| F2 | Reconnaître un katakana | voir → son | ~80 |
| F3 | Identifier une syllabe japonaise | entendre → identifier | ~80 syllabes/mora |

Pas de production pour les kana isolés (ça n'a pas de sens). La production arrive au niveau du mot.
F3 est indépendant du script — hiragana et katakana partagent les mêmes sons.
Les combinaisons (きゃ), gemination (っ), sons longs (おう) sont des instances, pas des catégories séparées.

**CORE — 7 skill types (universels, difficulté croissante par instance)**

| ID | Skill type | Direction | Conditionnel |
|---|---|---|---|
| C1 | Perception audio | entendre → segmenter | Non |
| C2 | Compréhension orale | entendre → sens | Non |
| C3 | Reconnaissance kanji → sens | voir kanji → sens | Mots avec kanji |
| C4 | Lecture → prononciation | voir mot → son | Non |
| C5 | Lecture → sens | voir mot → sens | Non |
| C6 | Rappel oral | sens → son | Non |
| C7 | Rappel écrit | sens → écriture | Non |

Les instances vont du mot simple (犬) à la phrase complexe (食べなければならない).
C3 est un point d'entrée alternatif pour les sinophones (pas de prérequis kana).
Skills éliminés : kanji→prononciation isolé (s'apprend en contexte), prononciation séparée (intégré dans C6).

**CONNAISSANCE GRAMMATICALE — 7 skill types (prérequis pour instances complexes)**

| ID | Skill type | Instances |
|---|---|---|
| G1 | Particules (cas + finales) | ~25 (は, が, を, に, で, よ, ね...) |
| G2 | Conjugaisons | ~15 (て-form, ない, passé, potentiel, passif, causatif...) |
| G3 | Patterns de phrase | ~50+ (〜たい, 〜てもいい, 〜なければならない...) |
| G4 | Connecteurs | ~15 (けど, から, ので, のに...) |
| G5 | Keigo (système honorifique) | ~30 (sonkeigo, kenjougo, teineigo, substitutions verbales) |
| G6 | Système donner/recevoir | ~9 (あげる/もらう/くれる + formes en て + honorifiques) |
| G7 | Compteurs | ~30 (本, 枚, 匹, 台, 冊...) |

La conjugaison est UN skill type — les sous-règles (godan, ichidan, irréguliers) sont des instances.
Les adjectifs (い/な), copule (だ/です), négation rentrent dans G2 (conjugaisons).
Les conditionnels, comparaisons, citations rentrent dans G3 (patterns).
Les démonstratifs (こそあど), pronoms, adverbes, onomatopées sont du vocabulaire.

#### Graphe de dépendances

```
NIVEAU 0 — Points d'entrée
  F1 Hiragana    F2 Katakana    F3 Syllabe    C3 Kanji→sens (sinophones)

NIVEAU 1 — Vocabulaire simple (prérequis : kana)
  C1 Perception audio (← F3)
  C2 Compréhension orale (← C1)
  C4 Lecture→prononciation (← F1/F2)
  C5 Lecture→sens (← C4 ou C3, renforcé par C2)
  C6 Rappel oral (← C2 ou C5)
  C7 Rappel écrit (← C5, renforcé par C4)

NIVEAU 2 — Connaissance grammaticale (prérequis : vocab de base)
  G1 Particules
  G2 Conjugaisons (← verbes simples)
  G3 Patterns (← G1 + G2)
  G4 Connecteurs
  G5 Keigo (← G1 + G2 + G3 basiques)
  G6 Donner/recevoir (← G2)
  G7 Compteurs (← nombres)

NIVEAU 3 — Instances complexes des 7 skills core
  C1-C7 avec phrases, textes, dialogues (déverrouillés par grammaire)
```

**Dépendances fines entre skills core :**

| Skill | Prérequis strict | Recommandé (renforce) |
|---|---|---|
| C1 Perception audio | F3 | — |
| C2 Compréhension orale | C1 | — |
| C3 Kanji→sens | Aucun (point d'entrée) | — |
| C4 Lecture→prononciation | F1 ou F2 | — |
| C5 Lecture→sens | C4 ou C3 (deux chemins) | C2 |
| C6 Rappel oral | C2 ou C5 (au moins un réceptif) | Les deux |
| C7 Rappel écrit | C5 | C4 |

**Points d'entrée :** F1, F2, F3 (universels) + C3 (sinophones)
**Renforcement mutuel :** C5↔C6 progressent en parallèle (pas de cycle bloquant)

### Cross-Pollination — Validation contre CEFR, JF Standard, JLPT

**Focus :** Confronter la taxonomie de 17 skill types aux frameworks académiques pour identifier les trous

**7 écarts potentiels analysés :**

| # | Gap | Source | Verdict |
|---|---|---|---|
| 1 | Interaction (turntaking, clarification) | CEFR, JF Standard | ❌ Skill composé — pas atomique |
| 2 | Construction de discours | CEFR | ❌ Skill composé — émerge des atomiques |
| 3 | Compréhension fonctionnelle (lire un menu, etc.) | CEFR, JF, JLPT | ❌ Instances contextualisées de C2/C5 |
| 4 | Choix de registre en contexte | CEFR, JF | ⚠️ Instance avancée de G5 (keigo) — suffisant pour le MVP |
| 5 | Médiation | CEFR 2020 | ❌ Hors scope A1-A2 et hors scope app |
| 6 | Pitch accent / contrôle phonologique | CEFR | ⚠️ Intégré dans C6 (rappel oral) — le shadowing couvre ce besoin |
| 7 | Interaction écrite | CEFR | ❌ Skill composé (lecture + production + contexte) |

**Conclusion :** Le modèle à 17 skill types couvre bien le terrain atomique. Les gaps sont soit des skills composés (traités plus tard), soit des dimensions de progression (pas des skill types manquants). Aucun nouveau skill type ajouté.

**Décisions prises :**
- Keigo : G5 suffit pour le MVP, on itérera plus tard
- Pitch accent : intégré dans C6, pas de skill séparé — le shadowing est la meilleure approche
